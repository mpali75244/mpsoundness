# GenLayer Spinner

An original lightweight animated loading spinner designed for the GenLayer Portal.

## Concept

**Layer Formation / Intelligence in Motion**

The visual combines layered orbital motion, a central GenLayer-inspired geometric mark, moving data nodes, and opposing motion to create depth while remaining readable at small sizes.

## Technical

- Pure SVG animation
- No JavaScript
- No external dependencies
- `currentColor` compatible for theming
- Designed for light and dark backgrounds
- Target sizes: 16 / 24 / 32 / 48 / 64 px
- Main cycle: 2.8 seconds
- Infinite loop with continuous motion

## Files

- `genlayer-spinner.svg` — production spinner
- `demo.html` — browser preview

## Usage

```html
<img src="genlayer-spinner.svg" width="32" height="32" alt="Loading">
```

For full theme control, inline the SVG so `currentColor` follows the surrounding UI.
